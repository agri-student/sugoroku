# キャラクター画像

このディレクトリに置いた画像ファイル（`.png` / `.jpg` / `.svg` など）は、
サーバーの `GET /api/characters` により自動的に一覧化され、
プレイヤー画面のキャラクター選択に表示されます。

- 初期状態では動作確認用の SVG プレースホルダー（`character1.svg` 〜 `character6.svg`）を同梱しています。
- Gemini 等で生成した PNG 画像を追加する場合は、このディレクトリにファイルを置くだけで反映されます（サーバー再起動不要）。
- 表示は正方形想定。100〜512px 程度の正方形画像を推奨します。
