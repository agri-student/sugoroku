# キャラクター画像（Geminiで生成した画像の入れ方）

このフォルダに画像ファイルを置くだけで、プレイヤー画面のキャラクター選択に
**自動で表示**されます（サーバーの `GET /api/characters` が中身を一覧化します）。
プログラムの書き換えは不要です。

## 手順（Geminiで作った画像を使う）

1. Gemini で好きなキャラクター画像を生成し、PNG（または JPG）で保存する。
   - おすすめの指示例：「農業テーマの、正方形・背景が透明か白の、かわいいマスコットキャラクター」
   - 例：トラクター、かかし、野菜の妖精、農家さん、牛・にわとり など
2. 保存した画像を **このフォルダ（`public/assets/characters/`）に入れる**。
   - ファイル名は自由（英数字推奨）。例：`tomato.png`, `tractor.png`
3. すでにサーバーが起動している場合は、**プレイヤー画面を再読み込み**すれば反映されます。
   （サーバーの再起動は不要です）

## 画像のおすすめ仕様

- **正方形**（例：256×256 〜 512×512px）。丸く切り抜いて表示されます。
- 背景は**透明（PNG）**か白だと、コマとして見やすいです。
- 拡張子は `.png` / `.jpg` / `.jpeg` / `.gif` / `.webp` / `.svg` に対応。
- 枚数の上限はありません（6班より多くてもOK。班ごとに好きなものを選べます）。

## 画像サイズについて（タブレット運用時の注意）

キャラクター選択画面では、このフォルダの画像を**すべて読み込みます**。
Gemini が生成した画像はそのままだと 1枚 4〜5MB になることがあり、枚数が多いと
校内Wi-Fi 経由のタブレットで表示に時間がかかります。

- 目安：**1枚 200KB 以下**（512×512px 程度）に縮小しておくと快適です。
- Windows なら「ペイント」でサイズ変更 → 上書き保存でも十分です。
- 表示は丸く切り抜かれるので、**正方形**にしておくと収まりが良くなります。
